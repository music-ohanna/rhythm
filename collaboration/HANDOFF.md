## 1. 이번 UI 개선 세션 구현 내용 (`88c8a70`)

- `[▶ 이 마디 듣기]` 및 `[▶▶ 전체 듣기]` 버튼과 재생 아이콘이 시각적으로 정중앙에 균형 있게 정렬됨.

### ③ 마디 이동 탭 디자인 쇄신 (조잡한 동그라미 ➔ 깔끔한 사각형 탭)

## SAVE-FIX-001 — 저장 작품 파일 복원

- **변경 파일**: `app.js`
- **원인**: 내보낸 HTML에 삽입되는 `app.js` 안의 `</script>` 텍스트가 바깥 `<script>`를 조기에 닫아, 저장 파일이 JavaScript 구문 오류와 빈 화면으로 열림.
- **수정**: 저장 시 CSS·JavaScript 안의 종료 태그를 각각 `<\/style>`, `<\/script>`로 이스케이프하고, 앱 JavaScript를 읽지 못하면 저장을 중단하고 안내함.
- **보존**: 저장 상태의 4마디 작품, 빠르기, 악기, 메트로놈, 보기 설정과 선택 악기 실음 포함 로직 및 기존 `불러오기` 형식을 유지함.
- **검증**: `app.js` 구문 검사, 내보낼 스크립트의 조기 종료 방지, 작품·소리 설정 직렬화 필드 확인 완료.
