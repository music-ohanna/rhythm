# 📋 기능 구현 명세서 (SPEC)

> **명세 ID**: SPEC-001  
> **제목**: 현재 리듬 창작 프로토타입 기준선 안정화  
> **소유자**: Codex  
> **상태**: 사용자 승인 대기 (WAITING_FOR_USER_APPROVAL)  
> **기준 커밋**: `65e5192934257ea1420ab4ebdb1bf0b764737141`  
> **대상 브랜치**: `main` (로컬 작업만 허용, 푸시·배포 금지)

## 1. 목적

현재 `index.html`과 `assets/`에 누적된 미커밋 프로토타입을 보존하면서, 최근 사용자 요구가 실제로 동작하는지 검증하고 필요한 최소 보완만 수행한다. 이 작업의 결과는 이후 기능 개발과 논문용 검증의 기준선이 되는 하나의 감사 가능한 커밋이다.

## 2. 구현 범위

### 2.1 기존 변경 보존 및 구조 확인

- 현재 작업 트리의 기능을 처음부터 다시 작성하지 않는다.
- 관련 없는 리팩터링, 전면적인 CSS 재작성, 파일 이동 및 기능 삭제를 하지 않는다.
- `MULTI_MEASURE_PLAN.md`와 `assets/audio/`의 기존 자료 및 출처 기록을 보존한다.
- 앱 실행에 실제로 필요한 오디오 파일만 사용하되, 라이선스·출처가 불분명한 파일을 새로 추가하지 않는다.

### 2.2 4마디 작품·한 마디 집중 편집

- 작품은 최대 4마디를 유지하고 화면에는 현재 마디를 크게 표시한다.
- 이전 화살표는 악보 왼쪽 여백, 다음 화살표는 악보 오른쪽 여백에 배치한다.
- 화살표와 마디 선택 버튼은 데스크톱과 스마트폰에서 누를 수 있어야 한다.
- 전체 작품 재생 시 1마디부터 시작하고, 작성된 마지막 마디까지만 반복 재생한다.
- 재생 중 마디 화면이 현재 재생 마디에 맞춰 바뀌며, 다음 마디를 준비할 수 있는 표시를 유지한다.
- 악기 변경은 재생을 중단하지 않고 다음 발생 음부터 반영한다.

### 2.3 재생·음가·박자 규칙

- 재생 중인 버튼은 `중지` 상태를 명확히 표시하고 다시 누르면 즉시 멈춘다.
- 온음표와 붙임줄로 연결된 음은 표기된 음가만큼 지속한다. 타악기 실음은 무리한 음원 늘이기 대신 감쇠 꼬리 또는 합성 지속음을 사용하되, 다음 음의 시작 시점은 바꾸지 않는다.
- 4/4박자의 마디 합계는 4박, 6/8박자의 마디 합계는 여섯 개의 8분음표 단위로 판정한다.
- 6/8박자에서는 셋잇단음표 입력을 제공하지 않는다.
- 6/8박자에서 기존 4분음표를 선택한 뒤 점을 붙여 점4분음표로 바꿀 수 있어야 하며, 변경 후의 마디 합계로 초과 여부를 판정한다.
- 메트로놈과 실음의 첫 박이 체감상 어긋나지 않도록 같은 오디오 시간축에서 미리 예약한다.

### 2.4 예시 감상·따라 만들기·오류 안내

- 4/4 예시는 음표, 쉼표, 붙임줄을 모두 포함한다.
- 권장 예시 구조는 다음과 같다.
  - 1박: 4분음표
  - 2박: 8분음표 2개
  - 3박: 8분쉼표 + 8분음표
  - 4박: 붙임줄로 연결된 8분음표 2개
- 예시 감상 후 `따라 만들기`를 시작하면 목표 음표·쉼표·붙임줄을 연한 회색으로 악보에 표시한다.
- 정답 검사는 무작위 클릭을 유도하지 않도록 최소한 다음 오류 유형을 구분해 원인과 수정 방법을 함께 안내한다.
  - 음표·쉼표 종류 오류
  - 음가 또는 개수 오류
  - 박 안의 위치 오류
  - 붙임줄 연결 오류
  - 마디 길이 초과 또는 미완성
- 경고 메시지는 화면 중앙의 읽기 쉬운 형태로 표시하며 악보 조작을 불필요하게 오래 막지 않는다.

### 2.5 팔레트 드래그 입력

- 아래 음표·쉼표 팔레트의 기호를 악보로 드래그해 입력할 수 있다.
- 마우스와 터치 입력을 모두 지원한다.
- 놓는 위치는 유효한 리듬 격자에 맞춰지고, 마디 초과나 겹침이 발생하면 입력하지 않은 채 구체적인 이유를 안내한다.
- 기존 클릭 입력도 그대로 유지한다.

### 2.6 반응형 최소 기준

- 데스크톱, 일반 스마트폰 세로 화면, 태블릿 폭을 각각 확인한다.
- 스마트폰에서 핵심 순서는 `마디 선택 → 악보 → 기호 팔레트 → 빠르기·메트로놈·악기·표시 옵션 → 재생`으로 접근 가능해야 한다.
- 가로 스크롤이 필요하더라도 현재 마디 전체와 좌우 이동 버튼을 찾을 수 있어야 한다.
- 터치 대상은 서로 겹치지 않고, 경고·도움말·선택 메뉴가 화면 밖으로 잘리지 않아야 한다.

## 3. 음악교육적 고정 규칙

- V자 리듬, 정간보 블록, 강약 표시는 각각 독립적으로 켜고 끌 수 있어야 한다.
- 4/4 강약은 `강-약-중강-약`, 6/8 강약은 `강-약-약-중강-약-약`을 유지한다.
- 6/8은 `3+3`의 겹박 구조를 내부 계산과 V자 방향에 반영하되 화면에 불필요한 `3+3` 문구를 표시하지 않는다.
- V자 각도, 숫자 간격, 한 줄 리듬 악보 및 음표 모양을 임의로 변경하지 않는다.
- 자유 필기 기능은 다시 추가하지 않는다.

## 4. 제외 범위
