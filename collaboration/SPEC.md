# 📋 기능 구현 명세서 (SPEC)

> **명세 ID**: SPEC-002  
> **제목**: 초등학생용 화면 단순화와 도움말·출처 정리  
> **소유자**: Codex  
> **상태**: 재감사 후 수정 요청 (CHANGES_REQUESTED)
> **기준 커밋**: `d0082e793537d7838ba92db365a0d37e42cd41ba`  
> **권장 작업 브랜치**: `ui/spec-002-simplify`

## 1. 목표

기존 기능과 음악 규칙은 유지하면서, 초등학생이 처음 보았을 때 선택지가 많아 보이지 않도록 화면을 단순화한다. 현재 필요한 조작만 크게 보여 주고 설정·제출·세부 설명은 필요할 때 펼쳐 보게 한다.

## 2. 핵심 설계 원칙

1. 한 화면에서 같은 중요도의 버튼을 나열하지 않는다.
2. 학생의 기본 흐름을 `리듬 입력 → 듣기 → 수정` 세 단계로 보이게 한다.
3. 세부 설정은 `보기·설정` 안에 숨기되 기능 자체는 삭제하지 않는다.
4. 버튼 이름은 초등학생이 바로 이해할 수 있는 짧은 동사형 표현을 사용한다.
5. 스마트폰 세로 화면을 먼저 설계하고 데스크톱·태블릿으로 확장한다.

## 3. 기본 화면 정보 구조

### 3.1 상단

- 앱 제목은 한 줄로 유지한다.
- 항상 보이는 기능은 `되돌리기`, `지우기`, `도움말`, `보기·설정`만 둔다.
- 붙임줄은 상시 상단 버튼에서 빼고, 음표 선택 또는 입력 도구 영역에서 사용할 수 있게 한다.
- 박자 선택은 모든 박자 버튼을 나열하지 않는다. 현재 박자 하나를 표시하고 누르면 `2/4·3/4·4/4·6/8` 선택지가 열린다.
- 단계 연습과 작품 제출은 `도움말/학습` 또는 `보기·설정`의 보조 메뉴로 이동한다.

### 3.2 마디 이동

- `1마디·2마디·3마디·4마디` 네 버튼을 항상 노출하지 않는다.
- 기본 표시는 악보 좌우의 화살표와 중앙의 짧은 진행 표시를 사용한다.
  - 예: `‹  ● ○ ○ ○  ›` 또는 `‹  1 / 4  ›`
- 현재 마디와 작성 상태는 색 또는 작은 점으로 구분한다.
- 진행 표시를 누르면 네 마디 목록을 펼쳐 바로 이동할 수 있게 한다.
- 작품은 여전히 최대 4마디이며 재생·저장 데이터 구조는 바꾸지 않는다.

### 3.3 악보와 입력표

- 악보를 화면의 가장 큰 영역으로 유지한다.
- 음표·쉼표 입력표와 두 재생 버튼은 기본 화면에 유지한다.
- 현재 마디 연주와 작품 전체 연주는 색과 아이콘으로 구분하되 문구는 짧게 한다.
  - `▶ 이 마디 듣기`
  - `▶▶ 작품 듣기`
- 빠르기, 메트로놈, 악기는 한 줄의 `소리` 영역으로 묶는다.
- V자 리듬·정간보·강약 체크박스는 `보기·설정` 펼침 영역으로 이동하고 기본값은 모두 켠 상태를 유지한다.

## 4. 도움말 간소화

- 첫 화면에는 다음 세 문장 정도만 보여 준다.
  1. `아래 음표나 쉼표를 눌러 악보에 넣어요.`
  2. `듣기 버튼을 눌러 만든 리듬을 들어요.`
  3. `바꾸고 싶으면 지우거나 되돌리기를 눌러요.`
- 세부 설명은 `더 알아보기`를 눌렀을 때 항목별로 펼친다.
- 한 단락은 최대 2문장으로 제한한다.
- 악기 설명은 소리의 특징과 학습 용도만 짧게 쓴다.
  - 장구: `부드럽고 다양한 장단을 들려줘요.`
  - 꽹과리: `밝고 힘찬 소리로 강한 박을 느끼기 좋아요.`
  - 우드블록: `짧고 맑은 나무 소리예요.`
  - 드럼: `또렷하고 단단한 타격 소리예요.`
- 도움말 본문에서 음원 기관명, 라이선스 전문, 긴 출처 설명은 제거한다.
- 4/4·6/8, V자 리듬, 메트로놈, 표시 체크박스에 대한 핵심 설명은 삭제하지 않고 짧게 재작성한다.

## 5. 하단 출처 표기

- 화면 맨 아래에 작고 흐린 글씨의 출처 영역을 추가한다.
- 권장 문구:

  `제작: 오한나 (muse@frano.kr) · 국악 음원: 국립국악원 · 우드블록: hollandm/Freesound (CC0) · 드럼: menegass/Freesound (CC0)`

- 이메일과 원문 출처는 접근 가능한 링크로 제공한다.
- 작은 글씨를 사용하되 스마트폰에서도 읽을 수 있는 최소 크기와 대비를 유지한다.
- 상세 라이선스 정보는 기존 `assets/audio/SOURCES.md`에 그대로 보존한다.

## 6. 기능 보존 범위

- 4마디 데이터, 마디별 되돌리기, 현재/전체 반복 재생
- 4/4·3/4·2/4·6/8 및 6/8 겹박 규칙
- V자 리듬·정간보·강약 표시
- 메트로놈·빠르기·악기 선택
- 예시·따라 만들기·오류 안내
- 음표·쉼표 클릭 및 드래그 입력, 붙임줄, 점음표, 삭제
- 작품 HTML 제출 기능

## 7. 제외 범위

- 음악 계산·재생 타이밍·음원 교체
- Canvas 음표와 V자 모양 변경
- 신규 기능 추가
- 4마디를 초과하는 작품
- 서버·계정·교사 대시보드
- 사용자 승인 전 `main` 병합, 푸시 또는 배포

## 8. 구현 절차

1. 안티그래비티는 코딩 전에 데스크톱과 스마트폰의 간단한 와이어프레임 2안을 제시한다.
2. 사용자가 마디 표시 방식(`점 4개` 또는 `1/4`)과 메뉴 배치를 선택한다.

## EXPERT-REVIEW-003 — 가로 2줄(한도막 형식) 8마디 네비게이터 및 상단 박자 선택 재배치

### 1. 세로 리모컨 제거 및 악보 캔버스 가로 100% 원복

- 악보 Canvas가 모바일/스마트폰 화면에서 찌그러지지 않고 100% 가로 폭으로 넓고 쾌적하게 확장되도록 원복.

### 2. 음악교육적 가로 2줄(4마디+4마디) 마디 이동 네비게이터
- 8마디 악보를 한도막 형식(4마디 1행, 총 2행)에 맞춰 가로 2줄 배열로 정돈:
  - 1행: `[1마디] [2마디] [3마디] [4마디]`
  - 2행: `[5마디] [6마디] [7마디] [8마디]`
- 스마트폰 및 데스크톱 모두에서 4개씩 2줄로 깔끔하게 핏팅되어 터치 및 시각적 직관성 극대화.

### 3. 박자 선택 드롭다운 상단 헤더 재배치 및 표기 복원
- `meterSelect` 드롭다운을 상단 헤더 영역(`header`)으로 이동.
- 표기를 `4/4 박자`, `3/4 박자`, `2/4 박자`, `6/8 박자`로 잘림 없이 크고 또렷하게 표시.

## SAVE-FIX-001 — 저장 작품 HTML 복원

### 목표

`악보 저장`으로 내려받은 HTML이 빈 화면이 되지 않고, 작성한 마디·박자·빠르기·악기·메트로놈·보기 설정을 복원해 독립적으로 재생되게 한다. 저장 파일은 기존 `불러오기`로 다시 열어 수정할 수 있어야 한다.

### 범위

- 내보낸 HTML에 삽입되는 앱 JavaScript 안의 `</script>` 종료 태그를 안전하게 이스케이프한다.
- 저장에 필요한 앱 JavaScript를 가져오지 못하면 빈 파일을 만들지 않고 오류를 알린다.
- 기존의 상태 인코딩, 선택 악기 실음 포함, `불러오기` 형식은 유지한다.

### 완료 기준

- 저장 HTML을 단독으로 열었을 때 빈 화면이나 JavaScript 구문 오류가 없다.
- 저장 당시의 작품과 소리 설정이 복원된다.
- 저장 HTML을 창작 앱의 `불러오기`로 열어 계속 편집할 수 있다.

## SPEC-003 — C장조 음높이(실음) 리듬 창작 및 연주 기능

### 목표

창작한 리듬을 C장조 8음계(도·레·미·파·솔·라·시·도)의 실음과 함께 들을 수 있는 기능 옵션을 추가하여, 학습자가 리듬 창작 활동이 실제 음악적 멜로디로 연주되는 경험을 직관적으로 하게 한다. 사용자가 원할 때 언제든지 기존 단음/타악기 리듬 모드로 전환하거나 복원할 수 있도록 안전한 토글 방식으로 구현한다.

### 핵심 요구사항 및 범위

1. **C장조 음높이(실음) 소리 토글**:
   - 보기·설정 및 소리 컨트롤 영역에 `🎹 C장조 음높이(실음) 재생` 토글 버튼 추가.
   - ON 시 창작한 리듬 음표가 C4~C5 계음 멜로디 실음으로 연주됨.
   - OFF 시 기존의 단음/타악기 소리로 100% 동일하게 연주됨.

2. **계음 자동 할당 및 지정**:
   - 음표 생성 시 C장조 계음이 자연스럽게 배치됨.
   - 계음 변경 버튼/뱃지 선택으로 음표의 계이름(도·레·미·파·솔·라·시·도)을 손쉽게 변경 가능.

3. **실음 음원 합성 (Web Audio API)**:
   - C4(261.63Hz) ~ C5(523.25Hz) 주파수 기반 풍부하고 따뜻한 유율 음원 합성.
   - 붙임줄(Tie) 음표는 끊어짐 없이 매끄러운 서스틴 연주 지원.

### 완료 기준

- [ ] `C장조 음높이(실음)` 토글 ON 시 창작 리듬이 C장조 멜로디로 연주된다.
- [ ] 토글 OFF 시 기존 타악기 및 단음 리듬 소리로 완전 복원된다.
- [ ] 각 음표의 계이름(도~도)을 자유롭게 변경하여 조작할 수 있다.
- [ ] 기존 악보 저장/불러오기, 박자 규칙, 모바일 반응형 디자인이 완전히 유지된다.
