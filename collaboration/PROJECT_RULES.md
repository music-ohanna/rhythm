# 📜 Final-Rhythm 공통 운영 규칙 (Single Source of Truth)

이 문서는 **안티그래비티(Antigravity)와 사용자 간 협업** 시 반드시 준수해야 하는 단일 원본 규칙 문서입니다.

> ⚠️ **2026-08-04 체제 변경**: Codex 토큰 소진으로 안티그래비티가 구현+감사 역할을 모두 단독 수행합니다.

---

## 1. 역할 및 소유권 (Solo 체제)

| 역할 | 담당 |
|---|---|
| **구현** | 안티그래비티 — 코딩, 반응형 테스트, 커밋, HANDOFF |
| **셀프 감사** | 안티그래비티 — 구현 후 AUDIT.md를 직접 작성·점검 |
| **명세 및 방향** | 사용자 — 요구사항 제시, 우선순위 결정, GitHub 배포 승인 |

---

## 2. Solo 운영 핵심 규칙 (10+1)

1. **작업 시작 전 필수 참조**: `PROJECT_RULES.md`, `SPEC.md`, `STATUS.md`, `AUDIT.md`를 반드시 먼저 읽는다.
2. **명세 범위 엄수**: `SPEC.md`에 명시된 범위만 구현하고, 임의 확장·변경 금지.
3. **음악 도메인 규칙 보존**: 박자(4/4, 6/8)·음가·V자 리듬 표기법을 임의 변경 금지.
4. **무분별한 정돈 금지**: 요청받지 않은 리팩터링, 스타일 재작성, 파일 이동 금지.
5. **기존 사용자 작업 보존**: 사용자가 작성·수정한 코드를 덮어쓰거나 삭제 금지.
6. **단위 커밋 지침**: 기능 하나당 하나의 명확한 Git 커밋.
7. **다각도 검증 필수**: 변경 시 데스크톱·스마트폰 반응형·4/4·6/8 박자·오디오 재생을 종합 검증.
8. **인수인계 기록**: `HANDOFF.md`에 변경 파일, 주요 함수, 커밋 해시, 검증 결과 기록.
9. **배포 승인 필수**: `main` 브랜치 푸시·GitHub Pages 배포는 사용자 명시적 승인 후 실행.
10. **셀프 감사 체크리스트**: 구현 완료 후 아래 **셀프 감사 체크리스트**를 직접 수행하고 AUDIT.md에 기록.
11. **STATUS 업데이트**: 모든 상태 전환 시 즉시 `STATUS.md` 갱신.

---

## 3. 셀프 감사 체크리스트 (Self-Audit)

안티그래비티가 구현 완료 후 스스로 아래 항목을 점검하고 `AUDIT.md`에 결과를 기록한다.

### 🔴 P1 — 즉시 수정 필수
- [ ] 브라우저 콘솔에 JS 오류가 없는가?
- [ ] 동일 ID(`id=`)가 HTML 내에서 중복되지 않는가?
- [ ] 동일 JS 함수가 두 번 이상 정의되지 않는가?
- [ ] 악보 저장(`downloadPlayableScoreHtml`) 동작하는가?
- [ ] 4/4 박자 1마디 재생이 정상 동작하는가?
- [ ] 6/8 박자 1마디 재생이 정상 동작하는가?

### 🟠 P2 — 다음 PR에 수정
- [ ] 모든 버튼 터치 영역이 최소 44px 이상인가?
- [ ] 모바일(375px~430px) 가로 레이아웃이 깨지지 않는가?
- [ ] iPad(768px~1024px)·Galaxy Tab(600px~800px)에서 정상 표시되는가?
- [ ] `previousMeasureButton` / `nextMeasureButton` ID가 각 1개만 존재하는가?

### 🟡 P3 — 권장
- [ ] 시각적으로 흰 글씨가 흰 배경에 묻히는 버튼이 없는가?
- [ ] 새로 추가한 기능이 기존 기능과 충돌하지 않는가?

## 5. STATUS 상태값

1. `DRAFT` — 명세 작성 중
2. `SPEC_APPROVED` — 사용자 명세 승인 완료
3. `IN_PROGRESS` — 안티그래비티 구현 중
4. `SELF_AUDIT` — 안티그래비티 셀프 감사 진행 중
5. `READY_FOR_USER_REVIEW` — 사용자 검토 요청
6. `CHANGES_REQUESTED` — 사용자가 수정 요청
7. `READY_TO_DEPLOY` — 배포 준비 완료
8. `DEPLOYED` — GitHub Pages / main 배포 완료
